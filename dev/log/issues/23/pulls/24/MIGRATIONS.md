## PHP and original regression

- [PHPUnit 13](https://phpunit.de/announcements/phpunit-13.html): raise PHP to 8.5, migrate the XML schema, retain the existing test semantics and assertions. PHPUnit's current configuration replaces legacy schema compatibility. The full check runs tests, PHPStan and the formatter.
- [PHPStan 2](https://phpstan.org/blog/upgrading-from-phpstan-1-to-2): migrate configuration/types to current analysis without adding baselines or ignoring newly found errors. Keep strict analysis over source and pipeline code.
- [PHP CS Fixer PHP85 migration](https://cs.symfony.com/doc/ruleSets/PHP85Migration.html): use the upstream migration rules instead of retaining older PHP syntax/configuration. JSON decoding uses JSON_THROW_ON_ERROR rather than duplicating error checks.
- The Dependabot regression was a repository test matching zizmor-action v0.8.0 after #22 selected v0.8.1. Reproduce with the original WorkflowPolicyTest and old workflow; baseline-regression.log fails, policy-regression-fixed.log and php-check.log pass. Test the action interface rather than a stale exact release string. Do not revert Dependabot.

## C# / .NET

Read [xUnit v3 migration](https://xunit.net/docs/getting-started/v3/migration), [MTP integration](https://xunit.net/docs/getting-started/v3/microsoft-testing-platform), [Coverlet MTP integration](https://github.com/coverlet-coverage/coverlet/blob/master/Documentation/Coverlet.MTP.Integration.md), [.NET 11 compatibility](https://learn.microsoft.com/en-us/dotnet/core/compatibility/11), and [NuGet central management](https://learn.microsoft.com/en-us/nuget/consume-packages/central-package-management).

SDK 8/net8 becomes SDK 11/net11; xunit 2 becomes xunit.v3 4. Native MTP replaces VSTest Test.Sdk, Visual Studio adapter and coverlet.collector with an executable test project and coverlet.MTP. The SDK selects Microsoft.Testing.Platform in global.json. Use platform-native test timeout and coverage arguments; remove obsolete collector/runsettings invocation. Pass TestContext cancellation tokens where required by the new analyzer. Central transitive pinning moves compatible Microsoft.Extensions/Bcl packages to 11 and MTP to 2.5.3 without scattered overrides. AI 3's removed telemetry overload blocks the remaining parent migration, documented with source and upstream discussion. DocFX is a restored, versioned local tool. Build, format, 21 tests with coverage, package, warning-free DocFX and 50 Bun script tests are covered by CI.

Dependabot's native [dotnet-sdk updater](https://devblogs.microsoft.com/dotnet/using-dependabot-to-manage-dotnet-sdk-updates/) covers both root and standalone global.json files in one grouped multi-directory entry. NuGet package updates remain configured separately because their updater does not maintain SDK pins.

## Rust

Read [edition 2024 migration](https://doc.rust-lang.org/edition-guide/rust-2024/index.html), [ureq 3 migration](https://github.com/algesten/ureq/blob/main/MIGRATE-2-to-3.md), and [lino-arguments releases](https://crates.io/crates/lino-arguments/versions). The Rust 1.100 toolchain/edition 2024 matches current language features. ureq 2→3 uses typed body JSON, its current header API and StatusCode error matching. Keep the 404 release-status behavior.

Edition 2024 makes environment mutation unsafe. Test environment-dependent paths in a child process with a bounded input and env_remove instead of mutating shared test process state or adding unsafe. Use current Clippy let chains/is_some_and and hoist frontmatter Regex construction. Native Cargo's pipeline manifest plus lock replace repeated unlocked rust-script installations in CI; standalone inline manifests stay current and retain the existing command interfaces. Root dev dependencies explicitly cover modules included by tests. Both graphs run fmt, all-target Clippy with warnings denied, tests and audit; root release/package builds are in CI. No general-purpose new build wrapper or concurrency framework is needed.

## Components evaluated

Prefer the ecosystem's built-in solution before adding a new dependency: native MTP over VSTest adapters, NuGet CPM over per-project version copying, uv's shared lock compilation over multiple independently resolved pip installs, Cargo multi-bin manifests over custom script caching, Changesets native add over a second release-note writer, native YAML anchors over duplicated workflow maps, Node/semver/Actions core over local approximations. Renovate was considered; retain the requested existing Dependabot service and cover every added manifest directory. Upstream compatibility blockers have concrete parent constraints and reports rather than forced transitive overrides.
