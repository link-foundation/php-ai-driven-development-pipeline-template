Other differing transitive releases in TRANSITIVES.md are distinct supported API lines selected by the latest parents. Each row records its immediate declaring parent and constraint. For example, Windows installers still consume CommonJS fs-extra/asar APIs and Rust target-specific dependencies retain independent windows-sys major lines. Forcing global major overrides would change consumer APIs. These are compatibility constraints, not vulnerable packages concealed by audit flags. All ecosystem audits cover the entire resolved trees, including development dependencies.

No custom general-purpose dependency mechanism is added: native Changesets add, command-stream cwd, lino environment mapping, Actions outputs, semver, Node runtime APIs, NuGet CPM, MTP and Cargo's locked multi-bin build replace earlier local implementations. Remaining fallback matches in workaround-inventory.txt implement application behavior (first Git commit, missing user configuration, Web Archive recovery); preserve those features.
